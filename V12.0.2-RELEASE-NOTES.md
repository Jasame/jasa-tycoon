
## V12.0.2 联机房间地图

房主可在等待房间更换九张地图，地图列表显示各自启动资金。更换后其他真人需重新准备；倒计时与对局中不能更换。结算后由房主发起再战，回到等待房间后可选新地图。服务端校验房主权限、地图范围、版本与请求去重。


## V12.0.2 Room map selection

The host can change maps in the lobby, including after a rematch; each choice shows starting cash. Other human players must ready again after a map change. Changes are rejected during countdown or active games. The server checks host authorization, map validity, revision and duplicate requests.

13 new room-map checks and existing full regression suites passed. Changes are limited to the lobby feature; previous broader experience improvements remain separate work. Physical device verification has not been performed.
