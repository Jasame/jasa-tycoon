# 环球大富翁 · World Tycoon v3

在线游玩：https://jasa.hk/tycoon/

纯 HTML/CSS/JavaScript，无构建步骤与第三方依赖。支持 2–4 人 AI 或本地轮流对局；暂不支持远程联网。

## v3 更新

- 地图专属机制：世界环球护照、亚洲交通收益、欧洲铁路通票、非洲生态补贴、北美建设折扣、南美冒险基金、大洋洲海岛假日、南极科研拨款。
- 存档中心：自动存档、5 个手动槽位、上一局备份、JSON 文件导入导出与数据校验。
- AI 根据对手租金预留现金、重视同色组、主动收购缺少的地产，并赎回抵押资产。对人类玩家的报价必须等待卖方答复。三档 AI 风格不改变骰子概率。
- 五步新手引导，介绍开局、移动、资产、交易与存档。
- 修复赎回金额的浮点误差，AI 售楼遵守均衡原则。所有弹窗暂停 AI，关闭后继续。

## 地图规则

| 地图 | 规则 |
| --- | --- |
| 世界 | 亲自到访八个颜色组，领取一次 ¥2,000 护照奖励 |
| 亚洲 | 未抵押枢纽租金提高 50% |
| 欧洲 | 经过起点时，每座未抵押枢纽额外奖励 ¥250 |
| 非洲 | 每次行动前，每处未开发且未抵押地产补贴 ¥100，最多 ¥500 |
| 北美 | 建筑造价降低 20%，按 ¥100 向上取整；售楼和估值使用实际造价 |
| 南美 | 每次抽取机遇卡后获得额外 ¥500 基金 |
| 大洋洲 | 免费停车补贴共 ¥800，停在自己的未抵押枢纽获得 ¥300 |
| 南极 | 每次行动前，每级建筑拨款 ¥100，最多 ¥800 |

原版城市地图继续保留。每张地图 32 格、20 处地产和 2 个枢纽；含地产建设、抵押、赎回、公开拍卖、现金收购、周期市场事件和资产榜。南极为架空科考经营场景。

## 存档与兼容

旧 v1/v2 对局自动迁移，保留其原有经济规则；新局启用 v3 地图机制。新开一局或恢复存档前，将当前对局写入“上一局自动备份”。手动槽位独立保留；覆盖时需要在界面确认。

存档位于当前浏览器 localStorage，清理网站数据会丢失本地进度；建议导出 JSON 文件。跨浏览器不会自动同步。存储空间不足时会提示，备份失败会阻止切换对局。

## 部署

将完整 tycoon 文件夹上传至网站根目录，访问 /tycoon/。上线前先备份旧目录。也可以直接打开 tycoon/index.html 体验；长期游玩建议通过静态网站服务器访问以保持稳定的存档来源。

## 验证

使用 Node.js 运行：

    node verify.cjs

35 项规则检查，包括地图收益、存档迁移/恢复/无效数据拒绝、拍卖结算、AI 主动报价与资金守恒、均衡售楼，以及八张地图的完整 AI 对局状态模拟。
