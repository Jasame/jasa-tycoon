# 环球大富翁 · World Tycoon

在线游玩：https://jasa.hk/tycoon/

## v2 功能

- 世界、亚洲、欧洲、非洲、北美洲、南美洲、大洋洲、南极洲 8 张主题地图，并保留原版城市地图。
- 每张地图 32 格、20 处地产、2 个交通枢纽；同色组建设、抵押、赎回、租金与破产清算。
- 2–4 人 AI 或本地轮流对局，休闲/标准/进阶三档 AI 投资风格及两档移动速度。
- 放弃购买进入公开拍卖；可向玩家或 AI 提出现金地产收购。
- 每 5 回合更新市场租金乘数，实时资产榜和最近 50 条旅程记录。
- 浏览器自动存档，兼容 v1 城市经典存档。地图切换在开启新局时生效，保存最近一局。

## 使用与部署

纯 HTML/CSS/JavaScript，无构建与第三方依赖。直接打开 tycoon/index.html，或用任意静态服务器托管。

宝塔：先备份现有 tycoon 目录，再将仓库内 tycoon 文件夹上传至网站根目录，访问 /tycoon/。

存档保存在当前浏览器的 localStorage；清除网站数据会清除存档，跨浏览器不会同步。暂不支持远程联网。

南极科考是架空经营场景，不代表真实土地交易。各地图采用统一经济参数以保持对局平衡；地名不构成疆界或主权主张。

## 验证

JavaScript 语法检查通过。地图完整性、拍卖赢家与流拍、交易资金守恒、市场租金、抵押免租和经典地图兼容等 24 项规则检查通过。
