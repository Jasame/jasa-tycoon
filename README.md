## 三步开始

1. 打开 [jasa.hk/tycoon](https://jasa.hk/tycoon/)，选择“新的一局”，设置地图、人数、头像与职业；也可直接继续当前浏览器的进度。
2. 认准带方框和编号的“我的棋子”。掷骰后，停在无主地产可购买或进入拍卖；再次停在自己的未抵押房产，可付费升级一级。
3. 需要和朋友远程玩时，点击“联机”创建房间并分享邀请码。朋友加入并准备后，由房主开始；空位可添加人机。

自动掷骰只代替掷骰，不替你买地、升级或交易。新手情境提示在前三回合按当前阶段出现，可以跳过。

## 关键规则

- **胜负**：约定回合结束时比较净资产，或成为最后一位未破产玩家。项目本金及融资欠款计入净资产。
- **到站升级**：必须再次停在已拥有、未抵押的房产；每次到访最多升一级，最高四级，无需集齐同色。单纯路过或刚买下不会触发；不能升级时会显示原因。
- **现金风险**：第 8 回合起每 4 回合结算维护费，扩张与升级可能增加维护、审计和检修支出。可通过售楼、抵押等筹集现金。
- **收购免打扰**：V10 新局可关闭本局收到的收购邀约；每次发出邀约后，卖方有三个回合冷却，其他买家也需等待。AI 主动邀约默认关闭。
- **地图路线**：每局选一次，稳健路线立即获得 ¥300；探索路线完成本图目标获得 ¥900，只计算选择后的进度，未完成无奖励。
- **逆风挑战**：第 6 回合起，资产低于存活领先者 65% 时，可自愿支付 ¥300 押金。截止当前回合加 4 回合，到访两处不同地产或枢纽，收回押金并获得 ¥900；到期或提前结局未完成不退款，每局限一次。

以上为当前新局规则。旧存档和既有房间按其启用的规则运行；新功能不会补造旧局历史。完整数值、例外和兼容范围见 [V10 说明](V10-RELEASE-NOTES.md) 及游戏内手册。

## 联机、存档与隐私

- 联机由服务器统一掷骰和结算，校验回合、资产权限、金额、版本号和唯一请求编号，重复请求不会重复结算。
- 快速房间为 12 回合、每阶段最多 90 秒；标准房间为 20 回合、每阶段 180 秒。实际整局时长取决于人数和决策，不承诺固定分钟数。
- 断线席位保留，可刷新或使用浏览器保存的座位恢复。阶段超时会执行默认操作，包括掷骰、放弃购买／竞价、拒绝交易或结束回合；欠款时优先清算资产。
- 同一浏览器的同一座位在多个标签页打开时，副本只读，可主动接管；跨设备操作仍由服务器规则校验。
- 等待房间最后一次变更后保留 24 小时，已开局／结束房间最后一次操作后保留 7 天。邀请链接与二维码只含房间码，不包含座位凭证。
- 本地对局自动保存，另有 5 个手动槽位、上一局备份及 JSON 导入导出。联机进度独立存放在服务器。
- 外观收藏和反馈摘要保存在当前浏览器，没有账号云同步；可用收藏护照手动合并，或用一次性恢复码转移联机座位。反馈不自动上传；手动导出的摘要不含姓名、房间码、凭证、存档、账本或自由文字。清除网站数据会重置本机数据。

## 本地运行与自行部署

前端使用 HTML、CSS 和原生 JavaScript；后端使用 Node.js 内置模块，**无需 npm 安装或前端构建**。二维码和简繁转换使用本地托管的第三方库，见 [第三方许可](THIRD-PARTY-NOTICES.md)。

本地查看前端可在仓库根目录运行静态服务器，例如：

```sh
python3 -m http.server 8080
```

随后打开 `http://localhost:8080/tycoon/`。这只提供本地 AI／同屏玩法；远程房间需要同源 `/tycoon/api/` 后端代理。

Node.js 20 环境可运行后端：

```sh
node server/server.cjs
```

默认监听 `127.0.0.1:8912`。自建联机需要同源反向代理和持久化目录，生产使用 HTTPS。现有宝塔环境升级使用 **`deploy-v11.sh`**；它不是任意服务器的通用首次安装脚本。配置、首次安装、备份和回退见 [部署指南](DEPLOYMENT.md)。
